# Уютная семейная

Адаптивное семейное PWA для закрытого круга близких. Сообщения, профили и фотографии хранятся в Supabase и не входят в этот репозиторий.

GitHub Pages публикует приложение из папки `dist` с помощью GitHub Actions. Публичные параметры приложения задаются при сборке; закрытые ключи остаются вне браузерного кода.
